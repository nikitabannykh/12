# Старый адрес на Vercel после переезда

`vercel.json` создаётся при переключении: в нём новый адрес сервиса (`https://<IP>.sslip.io` или свой домен).

- Проксируются на новый сервер (адрес в браузере не меняется): страницы записи `/p/*`, их статика `/_next/*` и картинки `/api/images/*`, приём заявок `/api/lead`, трекер `/t.js` и `/api/t`, `/privacy`, иконки, `/api/health` и `/api/cron/run`.
- Всё остальное — постоянный редирект (308) на новый адрес с тем же путём.

Данные на Vercel не хранятся: он только передаёт запросы.
